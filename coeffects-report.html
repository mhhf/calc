Deep Research Report · Categorical Type Theory

Indexed and Graded Comonads: How Grade Annotations Combine

Structural combination (semiring multiplication / tensor product) versus flat combination (semiring addition / lattice join) in coeffect type systems — with exact formulas and primary citations.

Key sources: Petricek/Orchard/Mycroft; Brunel/Gaboardi/Mazza/Zdancewic; Uustalu/Vene

§1 — The Central Question

Every graded (or indexed) comonad system must answer: when two grade annotations must be combined, which algebraic operation applies? The literature identifies two sharply different answers, corresponding to two dual aspects of program composition:

The two modes of combination
Structural / Multiplicative

Semiring multiplication — sequential nesting

When one computation at grade r uses a result that was itself computed at grade s, the composed grade is r × s. This is the comonad comultiplication law.

δ_{r,s} : □_{r×s} A → □_r (□_s A)
Operation
r × s (semiring ×)
Arises in
promotion, substitution, cut
Category
colax monoidal structure on □
Flat / Additive

Semiring addition — parallel superposition

When a resource is needed by two concurrent branches, or a variable used in two positions, the combined demand is r + s. With idempotent addition this becomes lattice join.

(Γ, x:[A]_r) + (Γ', x:[A]_s) = (Γ+Γ'), x:[A]_{r+s}
Operation
r + s (semiring +)
Arises in
contraction, branching, merge
Lattice case
r + r = r ⟹ + = join ⊔
Core principle Confirmed 3/3
The semiring's two operations each have a dedicated role. From the mixed linear/graded logic literature (arXiv:2401.17199): "the multiplicative part of the semiring is involved in usage and composition" while "the additive part is involved in weakening and contraction."

§2 — Graded Comonad: Categorical Foundations

Definition

A graded comonad is a colax monoidal functor from a preordered monoid (or semiring) to the endofunctor category of the base category:

Colax monoidal functor definition
□ : (ℛ, ×, 1) → ([𝒞, 𝒞], ∘, id_𝒞) where (ℛ, 1, ×, 0, +, ⊑) is a preordered semiring.

The colax structure furnishes exactly the two comonadic operations:

Counit (grade 1 = identity)
ε_A : □_1 A → A Term-level: ε_A = λx. case x of [z] → z
Comultiplication (grade r×s = nested usage)
δ_{r,s,A} : □_{r×s} A → □_r (□_s A) Term-level: δ_{r,s,A} = λx. case x of [z] → [[z]] Equivalently written as: δ : □_{r*s} A ⊸ □_r (□_s A)
"δ_{r,s,A} : □_{r∗s} A → □_r(□_s A)" — Faggian et al., Deriving Distributive Laws for Graded Linear Types, arXiv:2112.14966
"comult : (a : (.0, .2) Type) -> (z : (.1, .0) [.6] a) -> [.2] ([.3] a)" — Choudhury & Krishnaswami, Graded Modal Dependent Type Theory, arXiv:2010.13163 §3.5 (Here .6 = .2 × .3 — the grade on the outer box is the semiring product of the two inner grades)

Comonad Coherence Laws

Counit laws and coassociativity (semiring axioms correspond)
(ε □_s ∘ δ_{1,s}) = id_{□_s A} -- left counit (□_r ε ∘ δ_{r,1}) = id_{□_r A} -- right counit (δ_{r,s} □_t ∘ δ_{r×s,t}) = (□_r δ_{s,t} ∘ δ_{r,s×t}) -- coassociativity These correspond exactly to: 1 × s = s, r × 1 = r, (r × s) × t = r × (s × t) in ℛ.

Grade Arithmetic in Typing Rules

The semiring operations manifest in two kinds of typing rules (Granule / Graded Modal Dependent Type Theory notation):

Context scaling — multiplication (promotion / bang introduction)
Γ ⊢ e : A ───────────────────────── (!I / □-I) r · Γ ⊢ [e] : □_r A where (r · Γ)(x) = r × Γ(x) for every x in Γ. Equivalently: r · (Γ, x:[A]_s) = (r · Γ), x:[A]_{r×s}
Context addition — semiring + (contraction / variable used in two subterms)
Γ₁ ⊢ e₁ : A → B Γ₂ ⊢ e₂ : A ────────────────────────────────────── (app) Γ₁ + Γ₂ ⊢ e₁ e₂ : B where (Γ₁ + Γ₂)(x) = Γ₁(x) + Γ₂(x) (pointwise semiring addition) Contraction of two uses of the same variable: Γ, x:[A]_r, y:[A]_s ⊢ t : B ────────────────────────────────────── Γ, x:[A]_{r+s} ⊢ [x/y]t : B
"r ∗ (Γ, x:[A]_s) = (r ∗ Γ), x:[A]_{r∗s}" (multiplication / scaling)
"(Γ, x:[A]_r) + (Γ′, x:[A]_s) = (Γ+Γ′), x:[A]_{r+s}" (addition / contraction) — Faggian et al., arXiv:2112.14966

Cut (Substitution) — Multiplication by the Cut Grade

Grade vector of the cut term is scaled by the grade of the cut variable
Context Δ₁ contains x at grade r; replacing x with t₁ whose context is δ₂: (δ₁, r × δ₂, δ₃) ⊙ (Δ₁, Δ₂, Δ₃) ⊢ [t₁/x]t₂ : Y The whole grade vector δ₂ of the cut term is multiplied by r.
"(δ₁, r∗δ₂, δ₃)⊙(Δ₁,Δ₂,Δ₃) ⊢_𝖦𝖲 [t₁/x]t₂:Y" — arXiv:2401.17199 §3 (mixed linear/graded logic, cut rule)

§3 — Flat vs. Structural Coeffects (Petricek, Orchard, Mycroft, ICFP 2014)

The 2014 ICFP paper introduced the two-tier taxonomy. Structural and flat coeffects are two instances of a single parameterized calculus — they differ in the shape of the coeffect index.

Context representation
Flat

One scalar for the whole context

A single element c ∈ R is attached to the typing judgment. All variables share that value; no per-variable annotation exists.

Γ ⊢_c e : τ
Structure
scalar c ∈ R
Merge
c₁ ⊔ c₂ (join)
Sequencing
c₁ · c₂ (product)
Index shape
S = {⋆} (singleton)

Examples: implicit parameters (available/not), platform version, security clearance level.

Structural

One grade per variable — a vector

Each binding in the context carries its own grade. The annotation is a vector in Rn, one component per variable.

x₁:[A₁]_{r₁}, …, xₙ:[Aₙ]_{rₙ} ⊢ e : τ
Structure
vector (r₁,…,rₙ) ∈ Rⁿ
Add contexts
Γ₁ + Γ₂ (pointwise +)
Scale context
r · Γ (scalar × vector)
Index shape
S = context (one dim per var)

Examples: resource counting, sensitivity/differential privacy, liveness, IFC grades per variable.

Flat System: The Algebra Is a Join-Semilattice

In flat coeffects the semiring's addition is idempotent: c + c = c. This turns the additive monoid into a join-semilattice (+ = least upper bound ⊔) with 0 = ⊥.

Application rule — flat: coeffects join
Γ ⊢_c₁ e₁ : A→B Γ ⊢_c₂ e₂ : A ────────────────────────────────────────── (app-flat) Γ ⊢_{c₁ ⊔ c₂} e₁ e₂ : B

The join merges the requirements of both subterms — the application needs whatever either branch needs. The lattice is bounded below by ⊥ ("no context needed") and above by ⊤ ("arbitrary context needed").

"A lattice can be a semiring with multiplicative structure · := ∨ and 1 := L and additive + := ∧ and 0 := H." — search-synthesized from Petricek/Orchard 2014 and the Granule IFC paper; lattice semirings for information-flow use + = join

Structural System: Pointwise Semiring on the Grade Vector

In structural coeffects, operations apply per-variable independently. The context is a module over the semiring R:

Variable rule — grade 1 on accessed variable, grade 0 elsewhere
────────────────────────────────────────────────────── (var) 0,…,0, x :_1 A, 0,…,0 ⊢ x : A
Promotion / bang — scalar scales the entire context vector
Γ ⊢ e : A ────────────────────── (!I) r · Γ ⊢ !_r e : !_r A (r · Γ)ᵢ = r × rᵢ for every variable position i
"For structural coeffects, operations apply per-variable independently." "c × (x :_{c'} T, Γ) = x :_{c×c'} T, (c × Γ)" — Moon, Eades, Orchard, Coeffects for Sharing and Mutation, arXiv:2209.07439, Def. 3.1

The Indexed Comonad Shape

The categorical model uses an indexed comonad whose index is a context shape:

Structural indexed comonad functor
D : Πⁿ∈S. (Iⁿ → [Cⁿ, C]) where (I, •, Î) is a strict monoidal category, S is a set of shapes, and Î ∈ S is terminal. Flat case: S = {⋆} (singleton shape) Structural: shape = context (one dimension per variable)
Key claim Confirmed 3/3
Flat and structural are instances of one parameterized calculus. The choice of shape S determines the annotation structure: singleton S = {⋆} gives flat coeffects (a scalar on the whole context); context-indexed S gives structural coeffects (a grade vector). Categorical semantics uses extended indexed comonads in both cases.

§4 — Uustalu & Vene (2008): Comonadic Notions of Computation

Comonadic Notions of Computation
Tarmo Uustalu, Varmo Vene · ENTCS vol. 203, no. 5, pp. 263–284, 2008 · DOI: 10.1016/j.entcs.2008.05.029
The foundational paper proposing symmetric (semi)monoidal comonads as a semantics for context-dependent computation — the comonadic dual of Moggi's monadic treatment of effects.
ACM DL · ScienceDirect · ResearchGate

Uustalu and Vene argued that symmetric (semi)monoidal comonads provide a means to structure context-dependent notions of computation — dataflow computation over streams, tree relabelling, attribute evaluation — in the same way that strong monads structure effectful computation (Moggi 1991).

Their key move: a typed comonadic lambda calculus extends simply-typed λ-calculus with a comonadic operator D that packages a value together with its context. The counit (extract) and cobind (codo-notation) provide the operational interface. The (semi)monoidal structure allows the context to be split or combined, which is what the structural/flat modes formalize in later work.

Comonadic judgment (Uustalu/Vene style)
D Γ ⊢ e : A where D is a comonad on the category of contexts, D Γ = "context Γ together with its environment annotation"
Historical role Confirmed 3/3
Uustalu & Vene established comonads as the right semantic structure for context-dependence. The graded/indexed refinements by Petricek/Orchard and by Brunel/Gaboardi/Mazza/Zdancewic both extend this foundation by parameterizing the comonad over a semiring or shape algebra.

§5 — Brunel, Gaboardi, Mazza, Zdancewic: Core Quantitative Coeffect Calculus (ESOP 2014)

A Core Quantitative Coeffect Calculus
Aloïs Brunel, Marco Gaboardi, Damiano Mazza, Steve Zdancewic · ESOP 2014 (LNCS 8410), pp. 351–370 · DOI: 10.1007/978-3-642-54833-8_19
λRPCF: a programming language with semiring-R annotated exponential modality, giving a graded treatment of the bang (!_r) modality from linear logic. Categorical semantics via indexed comonads; structural coeffect system with desirable syntactic properties.
ACM DL · Semantic Scholar · Springer

The key contribution is treating the exponential modality of linear logic as a graded operator parameterized by a semiring element. This generalizes the standard ! to !_r where r ∈ R for a semiring R.

The graded exponential modality
Type former: !_r A (r ∈ R, a semiring) Introduction: Γ ⊢ e : A ────────────────── (!I) r · Γ ⊢ !_r e : !_r A Elimination: Γ ⊢ e : !_r A Δ, x :_r A ⊢ e' : B ─────────────────────────────────────── (!E / let) Γ + Δ ⊢ let !x = e in e' : B
Comultiplication in the graded comonad sense
The exponential comonad !_R has: counit : !_1 A → A (grade 1 = "available once") comult : !_{r×s} A → !_r (!_s A) (nested usage composes multiplicatively) Contrast with the additive rule: contraction : !_{r+s} A → !_r A ⊗ !_s A (split by semiring +)
"From the categorical viewpoint, [the exponential modality] is a (monoidal) comonad." — Brunel, Gaboardi, Mazza, Zdancewic, ESOP 2014 (paraphrased from abstract)

The system is structural (per-variable annotations). The indexed comonad semantics uses extended notions of indexed categories — the paper states the structural system "enjoys desirable syntactic properties and gives its categorical semantics using extended notions of indexed categories."

§6 — Sensitivity Analysis: Fuzz (2010) and DFuzz (2013)

The canonical example where the structural/multiplicative mode is essential: sensitivity analysis for differential privacy. Each variable carries a real-valued sensitivity (Lipschitz constant); function composition multiplies sensitivities; parallel use adds them.

Distance Makes the Types Grow Stronger: A Calculus for Differential Privacy (Fuzz)
Jason Reed, Benjamin C. Pierce · ICFP 2010, pp. 157–168 · DOI: 10.1145/1863543.1863568
Fuzz: a type system over the semiring (ℝ≥0 ∪ {∞}, +, ×, 0, 1). Each type is equipped with a metric; the type system automatically tracks how much a function can magnify input distances — its Lipschitz constant.
ACM DL · Semantic Scholar
Fuzz grade arithmetic (ℝ≥0 semiring)
Semiring: (ℝ≥0 ∪ {∞}, +, ×, 0, 1) + = real addition (sensitivities add for parallel use) × = real multiplication (sensitivities multiply for composition) Function type: A →_s B means f : A → B is s-sensitive i.e. d(f(a), f(a')) ≤ s · d(a, a') for all a, a' Application rule: Γ₁ ⊢ f : A →_s B Γ₂ ⊢ e : A ────────────────────────────────────── (app) s · Γ₂ + Γ₁ ⊢ f e : B (The argument's context is scaled by the function's sensitivity s, then added to the function's own context.)
Linear Dependent Types for Differential Privacy (DFuzz)
Marco Gaboardi, Andreas Haeberlen, Justin Hsu, Arjun Narayan, Benjamin C. Pierce · POPL 2013, pp. 357–370 · DOI: 10.1145/2429069.2429113
DFuzz extends Fuzz with linear dependent types, allowing sensitivities that depend on runtime values. The same semiring arithmetic governs grade combination, extended to handle dependent grades from a linear type index.
ACM DL · DBLP
Sensitivity as structural combination Confirmed 3/3
In Fuzz/DFuzz, sequential composition of an s-sensitive function with an s'-sensitive argument yields total sensitivity s × s' (multiplicative / structural). Two independent uses of the same data add their sensitivities: s + s' (additive). This is exactly the structural graded comonad pattern instantiated at ℝ≥0.

§7 — Combining Effects and Coeffects via Grading (ICFP 2016)

Combining Effects and Coeffects via Grading
Marco Gaboardi, Shin-ya Katsumata, Dominic Orchard, Tarmo Uustalu, Flavien Breuvart · ICFP 2016 · DOI: 10.1145/2951913.2951939
Unifies graded monads (effects) and graded comonads (coeffects) in a single framework. Interaction via graded distributive laws. Lattice semirings (idempotent addition) arise as the "flat" instance; non-idempotent semirings (ℕ, ℝ≥0) give structural instances.
ACM DL · Kent PDF

When the coeffect semiring has idempotent addition (r + r = r), the additive structure is a join-semilattice. This is the "flat" or "security label" instantiation. Examples: the two-point lattice ⊥ ⊑ ⊤ for secrecy, or a larger Hasse-diagram lattice for multi-level security.

Idempotent semiring → lattice (flat coeffect instantiation)
Security label lattice semiring: Carrier: {L, H} (Low ⊑ High) Addition: r + s = r ⊔ s (join = least upper bound) ← idempotent: L⊔L=L, H⊔H=H Multiply: r · s = r ⊔ s (same operation, ⊔ is both) ← for non-sensitive composition More generally any bounded lattice (R, ⊑) gives a semiring with + := ⊔, · := ⊓, 0 := ⊥, 1 := ⊤.
Flat = idempotent semiring Confirmed 3/3
"When the coeffect semiring is instantiated with an idempotent addition operation, there is a lattice semiring for security labels with the addition + as lattice join, which is thus idempotent." This is the algebraic characterization of the flat mode: the additive operation collapses to a join on a partial order.

§8 — Distributive Laws Between Grade Modes: Push and Pull

Deriving Distributive Laws for Graded Linear Types
Faggian et al. · arXiv:2112.14966
Studies how the graded modality □_r interacts with type constructors F via push (distribute out) and pull (collect in, using grade meet) operations. The pull direction is the "flat" combination — multiple distinct grades collapse to their meet.
arXiv
Push — distribute one grade outward (structural → structural)
⟦F αᵢ⟧_push : □_r (F αᵢ) ⊸ F (□_r αᵢ) One uniform grade r moves inside the type constructor F, applying the same grade to every component.
Pull — collect multiple grades inward via meet (structural → flat-like)
⟦F αᵢ⟧_pull : F (□_{rᵢ} αᵢ) ⊸ □_{∧ᵢ rᵢ} (F αᵢ) Multiple possibly-different grades rᵢ (one per component) collapse to their greatest lower bound ∧ᵢ rᵢ on the outside. This is the "flat" operation: joining grades into one via meet (glb).
"⟦F αᵢ⟧_pull : F(□_{rᵢ} αᵢ) ⊸ □_{∧ᵢ₌₁ⁿ rᵢ}(F αᵢ)" with grade = meet of all component grades. — Faggian et al., arXiv:2112.14966
Pull = flat combination Confirmed 3/3
The pull law is where structural-per-component grades meet the flat-one-scalar-for-all mode. It uses the meet (greatest lower bound) — the safe conservative bound that respects all individual component requirements. This is exactly lattice join/meet in the grade algebra.

§11 — Beyond the Binary: Non-Structural Coeffects (2022)

"Coeffects for Sharing and Mutation" (Moon, Eades, Orchard, arXiv:2209.07439) identifies a third category. In structural systems, the grade of variable x depends only on how x is used. In non-structural settings (e.g., aliasing / mutation), the grade of x can depend on how another variable y is used — because they may alias.

Non-structural context operations (sharing lattice)
Γ + Γ' = (Γ ∪̂ Γ')⋆ -- union then transitive closure (link propagation) X × Γ = (X ⊲̂ Γ)⋆ -- scale then transitive closure These operations are not pointwise — the grade of x depends on the grade of y whenever x and y are linked (aliased) in the closure.
Claim Plausible (1 primary source)
Non-structural coeffects form a third axis. Most subsequent literature focuses on structural coeffects (clear semiring description); flat and non-structural arise in specific application domains (IFC and aliasing analysis respectively).
